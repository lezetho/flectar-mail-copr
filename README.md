# Flectar Mail

> [!CAUTION]
> This is not the source repository for `Flectar Mail`. This is the repository for the COPR package of `Flectar Mail`. Issues related to `Flectar Mail` software should be reported [upstream](https://github.com/flectar/mail) instead.

Flectar Mail is a native Rust and Slint mail client with offline-first storage, Gmail and Microsoft account support, contacts, and calendars.

For more information visit the [Flectar Mail](https://flectar.com) website or the [upstream repository](https://github.com/flectar/mail).
